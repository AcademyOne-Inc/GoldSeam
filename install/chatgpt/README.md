# ChatGPT

GoldSeam is a remote MCP server over streamable HTTP with no authentication, at

```
https://goldseam.ksaworks.com/mcp
```

Add it wherever your ChatGPT surface accepts a remote MCP server — connectors in the app, or a
custom tool in the API and Agents SDK, where the same URL is given as an MCP server with no auth.

Then ask it something that names a school, and check the answer carries its source and snapshot date.
