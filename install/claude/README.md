# Claude — add GoldSeam as a custom connector

Works on **every plan, including Free**. About a minute, on a phone or a computer.

1. Open **Settings → Connectors** (in the app: **Customize → Connectors**).
2. Click **+ Add custom connector**.
3. Paste `https://goldseam.ksaworks.com/mcp` and click **Add**. Leave authentication empty — there is none.
4. In any chat, press **+ → Connectors** and switch **GoldSeam** on.

Ask it something:

> What nursing programs does Laramie County Community College offer, and what does one require?

If the answer names its source and its snapshot date, you are connected.

**On a Free plan** you get one custom connector, so this is the one to spend it on.

**In Claude Code or Claude Desktop**, the same address goes in an MCP config — see
[`../mcp.json`](../mcp.json).
